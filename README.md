# TeleMach
TeleMach is an amateur flight telemetry interface. While it isn't ready to be used with most of the microcontrollers at this stage, it could be a good starting point.
It uses a classic KSP style navball (fun fact: the nav.png is borrowed from a KSP forum).
It has some alert chimes for some situations (most of 'em are borrowed from various McDonell Douglas planes)
It uses a simple UV-Mapping method to project 2D navball image onto a "3D" sphere. 
It has some hardcoded situations like rising an alarm when drogue chute isn't deployed 25km AGL, but you can bypass them or trick them. Hardcodes are just for testing at the end of the day.
I plan to use it for a suborbital aerothermodynamic test capsule, so it will get occasional updates, and it will be fitted for some U-Blox GPS devices and Airborne 4G mode.
